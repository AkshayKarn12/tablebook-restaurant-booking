# 🍽️ TableBook – Restaurant Booking System

A modern full-stack Restaurant Booking System built using the MERN Stack (MongoDB, Express.js, React.js, Node.js). The platform allows users to discover restaurants, reserve tables online, manage bookings, and enjoy a seamless dining reservation experience.

## 🚀 Live Project

### 🌐 Live Website

https://tablebook-restaurant-booking.vercel.app

### 💻 GitHub Repository

https://github.com/AkshayKarn12/tablebook-restaurant-booking

## ✨ Features

* User Registration & Login

## ⚡ Important Note

Since the backend is hosted on Render's free tier, it may go to sleep after a period of inactivity.

### Step 1 — Wake up the Backend

Open:

https://tablebook-restaurant-booking.onrender.com/api/health

Wait until you see:

```json
{
  "status": "OK",
  "message": "Restaurant Booking API is running 🍽️"
}
```

### Step 2 — Open the Website

Visit:

https://tablebook-restaurant-booking.vercel.app

After the backend wakes up, the application will work smoothly and much faster.

## 🎯 Project Objective

The Restaurant Booking System was developed to simplify restaurant reservations by providing a centralized online platform where customers can search restaurants, check availability, and reserve tables without traditional phone-based booking methods.
